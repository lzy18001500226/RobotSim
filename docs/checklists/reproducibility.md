# Reproducibility Checklist

- [ ] Third-party repositories pinned to exact commits
- [ ] Docker image build is deterministic enough to reproduce
- [ ] No local absolute paths committed
- [ ] No vendor binary redistributed without permission
- [ ] One-command build documented
- [ ] One-command simulation launch documented
- [ ] Data / model downloads documented with checksums where practical
- [ ] Simulation and real-robot launch configs are separate
