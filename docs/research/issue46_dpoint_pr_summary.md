# Issue #46 — D-Point and Motor-Only OmniPicker Evidence

This Draft PR preserves the PR #84 D-site/sign-coordinate audit and adds a motor-only, source-mesh experiment. The D-site mapping is verified, and the existing CAD branch produces a functional kinematic preview across CAD q `+0.20…-0.10 rad`. The preview uses the official v1.4.0 visual meshes and remains explicitly unverified.

The maintainer's passive-joint alignment observation was checked against the pinned official URDF. Paired left/right root, B, C, and loop joint origins/axes match after side-name substitution, so no mirror-coordinate correction is supported. The screenshot is at CAD q `+0.05 rad`, outside the saved STEP sample range (`-0.32…0.00`); it is an analytic continuation. On source-backed q `-0.05` and `-0.10`, registered B/C/E MuJoCo anchors match the STEP pivots within `0.018 mm`. No mesh or joint offset was applied without source evidence. See the detailed report for anchor measurements and the exact source datum needed to resolve the positive-q view.

The real MuJoCo 3.3.6 test used one active right root motor, official opposite-root mimic, source-derived passive hinges, and D pin closures. It stopped after 55 `mj_step`s (`0.055 s`) when passive hinges drifted under gravity and reached `25.039 rad/s` before the root command left the open hold. Constraint-Jacobian rank shows 2 local DOFs per side after D closure; the required middle-to-loop coupling is absent from the URDF, public root-command script, and AP214 STEP relation entities. No follower actuators, unverified rate equality, bottle qpos write, or bottle contact test were used.

The bounded experiment also recorded the original collision baseline and evaluated only the four previously identified internal pair exclusions in its diagnostic model. Bottle/finger and bottle/table collision remained enabled. Bottle lift is `NOT RUN` because the root-only passive-motion gate failed. The right wrist collision STL has a much longer extent than the visual extension and intersects several right-hand collision surfaces in the existing static audit; the isolated gripper fixture did not include the wrist.

Full findings, exact missing manufacturer relation, per-joint traces, mobility rank, and reproduction path: [`issue46_motor_only_omnipicker.md`](issue46_motor_only_omnipicker.md). The external run, including the interactive kinematic preview, short physical failure video, original collision baseline, and artifact manifest, is under `reviews/issue-46/motor-only-passive-20261021T133518Z/`.

**Result:** the single-motor API is supported by the local RAICOM controller example, but the current articulated experimental topology is underactuated and unstable without one manufacturer-defined passive coupling per hand. The missing ratio/phase, tendon, or spring/coupler behavior must be supplied before a successful motor-only physical stroke or bottle test can be claimed.
