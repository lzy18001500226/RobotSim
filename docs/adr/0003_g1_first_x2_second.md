# ADR-0003: G1 first, X2 second

Status: Accepted

## Decision
Build the first end-to-end baseline on Unitree G1, then port to AgiBot X2.

## Rationale
G1 has a mature public MuJoCo / D435i / MID360 ecosystem and directly matches the lab's previous bottle-grasp direction.

The architecture must still remain robot-independent.
