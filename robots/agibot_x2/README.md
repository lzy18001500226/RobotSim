# AgiBot X2 Backend

This directory will contain only project-owned X2 adapter code and configuration.

Vendor packages / SDK deliveries should not be committed unless redistribution is allowed.
The official X2 Ultra base, OmniHand and OmniPicker model identities are kept
separate in the [robot asset registry](../../assets/robots/README.md). They are
not mechanically interchangeable, and the registry does not alter active
experiment runners.
